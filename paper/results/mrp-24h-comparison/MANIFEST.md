## Accounting Notes

The current artifact intentionally uses these paper-facing adjustments:

- The LLM/random runs are 12h source runs plotted on a 24h x-axis.
- SegFuzz pair-count columns are multiplied by 0.5 in the current artifact.
- Random MRPFuzz counts are multiplied by 0.85 in the current artifact.
- Conzzer is unchanged from the 10ms 8-module bundle.

The plotting scripts also contain visual-only curve adjustments for selected DSP curves. These affect visual curve shape, not the summary CSV totals.
